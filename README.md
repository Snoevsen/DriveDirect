# Mobile Development: DriveDirect 
DriveDirect is a project developed as part of the Mobile Development Course.


## Project Description 
DriveDirect has been built by using React Native and TypeScript, and the codebase covers key user journeys, including vehicle browsing, also as a guest user (ExploreScreen), active/reserved vehicle tracking (CarsScreen), emergency assistance (HelpScreen), and account settings (ProfileScreen).

### "react-native-safe-area-context" problems 

Incase the code has troubles finding "react-native-safe-area-context", try the following command to installing the missing package: 


```bash
npx expo install react-native-safe-area-context
```

As seen in this document: 
https://docs.expo.dev/versions/latest/sdk/safe-area-context/
